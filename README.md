## 🌟 الميزات الرئيسية

- ⏱️ **حالة اليوم والعد التنازلي المباشر**: معرفة هل أنت مداوم اليوم أم في راحة بلون وأيقونة مميزة مع عداد حي للوقت المتبقي حتى بداية أو نهاية الوردية.
- 👤 **تسجيل الاسم والتخصيص الكامل**: إمكانية تسجيل اسم المستخدم وتخصيص بطاقة الدوام باسمه (`✨ جدول فلان`).
- 📱 **متجاوب 100% مع الجوال والآيباد**: تصميم عصري بنظام Glassmorphism يدعم الهواتف (iPhone / Android) وأجهزة الآيباد والتابلت والشاشات الكبيرة.
- 🔄 **دعم كافة أنظمة الورديات**: الدوام الأسبوعي الثابت، نظام 24/48، 24/72، 24/24، 12 ساعة، والأسبوع بأسبوع.
- 🛠️ **منشئ الأنماط المخصصة**: بناء أي دورة عمل خاصة وتحديد تتابع الورديات وأيام الراحة بحرية.
- 📅 **التقويم التفاعلي متعدد العروض**:
  - عرض شهري كامل ملون.
  - خريطة حرارية سنوية (Yearly Heatmap).
  - جدول زمني للأيام القادمة (Timeline View).
- 🔁 **تسجيل التبديل والإجازات**: تسجيل الإجازات السنوية والمرضية وتبديل الورديات مع الزملاء.
- 🔍 **فاحص التواريخ المستقبلية**: معرفة حالة دوامك في أي مناسبة أو تاريخ قادم بضغطة زر.
- 🏖️ **مخطط الإجازات وفترات الراحة الذكي**: اكتشاف أقرب إجازة واقتراح أفضل الأيام لأخذ إجازة سنوية لمضاعفة أيام العطلة المتتالية.
- 📲 **تصدير ومزامنة**:
  - تصدير ملف `.ICS` للتقويم (Google Calendar, Apple Calendar, Outlook).
  - طباعة الجدول وحفظه بصيغة PDF.
  - نسخ احتياطي واستعادة للبيانات (JSON Backup).
- 🌙 **دعم الثيم الليلي والنهاري (Dark / Light Mode)**.
- 🌐 **دعم كامل للغتين العربية والإنجليزية (AR / EN)**.

## 🔄 أنظمة الدوام المدعومة

| النظام | الوصف | القطاعات الشائعة |
|---|---|---|
| **الدوام الأسبوعي** | 5 أيام عمل (الأحد - الخميس) ويومان راحة | الشركات والدوائر الحكومية |
| **استلام 24 / 48** | يوم استلام 24 ساعة ويومان راحة | القطاع الأمني، المستشفيات، الإسعاف |
| **استلام 24 / 72** | يوم استلام 24 ساعة و3 أيام راحة | الدفاع المدني، المراقبة والتحكم |
| **استلام 24 / 24** | يوم استلام 24 ساعة ويوم راحة (يوم بيوم) | الحراسات الأمنية والمواقع الميدانية |
| **نظام 12 ساعة (2-2-2)** | 2 نهار، 2 ليل، 2 راحة | المصانع، الطوارئ، التمريض |
| **نظام 12 ساعة (2-2-4)** | 2 نهار، 2 ليل، 4 راحة | قطاع النفط، البتروكيماويات، المحطات |
| **أسبوع بأسبوع (7 / 7)** | 7 أيام دوام متتالية و7 أيام راحة | المواقع البحرية والمناطق النائية |
| **نظام 14 / 14** | 14 يوم دوام و14 يوم راحة | مشاريع الحفر والتعدين |
| **الورديات الثلاثية (3 Shifts)** | صباحي (D)، مسائي (E)، ليلي (N)، راحة (O) | مراكز العمليات والاتصال |
| **النمط المخصص** | تخصيص أي تتابع أيام مخصص بحرية تامة | متاح لجميع المستخدمين |

## 💻 طريقة التشغيل

المشروع مبني بلغات الويب الأساسية بدون أي متطلبات معقدة:
- **HTML5**
- **Vanilla CSS3** (Glassmorphism & Responsive Design System)
- **Modern JavaScript (ES6+)**

### التشغيل المباشر:
افتح ملف `index.html` في أي متصفح (Chrome, Safari, Edge, Firefox).
